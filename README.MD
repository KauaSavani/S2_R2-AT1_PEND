# Manipulação do DOM com JavaScript

Projeto desenvolvido para a atividade de desenvolvimento web.

O objetivo é praticar manipulação do DOM utilizando JavaScript, criando interações com elementos HTML.

## 📚 Funcionalidades

### Exercício 1
Página onde o usuário digita seu nome e ao clicar no botão uma mensagem aparece na tela com o nome digitado.

### Exercício 2
Alterar o texto de uma página ao clicar em um botão utilizando JavaScript.

### Exercício 3
Adicionar itens dinamicamente em uma lista utilizando JavaScript.

### Exercício 4
Sistema de lista de tarefas utilizando Bootstrap:
- Verifica se o campo está vazio
- Exibe mensagem de erro ou sucesso
- Cria tarefas dinamicamente

### Exercício 5
Cada tarefa adicionada possui um botão **Remover**, que exclui a tarefa da lista.

### Exercício 6
Implementação de **checkbox para marcar tarefas como concluídas**, alterando o estilo da tarefa quando marcada.

## 🛠 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap
